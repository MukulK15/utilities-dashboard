📋 How to Use

  1. Prepare your Excel file with the following columns:
    • Utility Name - Name of the utility
    • Created Date - Date created (YYYY-MM-DD)
    • Utilizations - Number of times used
    • Savings Per Use - Cost savings per utilization ($)
  2. Click "Upload Excel File" to select your file
  3. Click "Load Data" to process and visualize
  4. The dashboard will automatically calculate total savings and year-wise trends
  5. To load updated data from the same file, click "Load Data" again
